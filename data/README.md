# Data provenance

`manuscript_reported/` contains selected values manually transcribed from the supplied manuscript, not freshly computed results. It is not an input catalogue and must not be used to tune an astronomical implementation to the published answers.

The prepared companion bundle includes a source manifest with byte lengths and SHA-256 hashes of uploaded originals. That manifest and the original scripts remain pending publication to GitHub. The input Hipparcos cache, DE422 kernel, original result files, and software environment were not provided. Do not invent catalogue rows or original package versions.
